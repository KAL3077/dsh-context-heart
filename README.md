# dsh-context-heart —— 上下文爱心桌宠

屏幕角落里一颗红心，随上下文用量变化：鲜红跳动 → 出现裂纹 → 发黑掉渣 → 破碎、只剩余震。
把「还剩多少上下文」变成看得见的身体感受。

## 交互

| 操作 | 行为 |
|---|---|
| 左键点 | 展开 / 收起详情（血条 + 剩余百分比 + 分段占用 + 还剩多少 token） |
| 左键拖 | 挪位置（存 `localStorage.ctxheart.pos`） |
| 滚轮 | 缩放 0.6–2.4（存 `localStorage.ctxheart.zoom`） |
| 右键 | 菜单：详情 / 大小 / 重置位置 / 隐藏 |

隐藏后原地留一颗小红点，点一下复原（隐藏状态不跨刷新，重开页面就会回来）。

## 档位

| 用量 | 表现 |
|---|---|
| 0–25% | 鲜红饱满，跳动快 |
| 25–50% | 转暗红，出现第一道主裂纹 |
| 50–75% | 裂纹增多，露出黑芯，边缘崩口，掉碎片，跳动变慢 |
| 75–100% | 大面积崩口发黑，几乎不跳，边缘红光警示，常显百分比 |

实现：一个 SVG 心形 + 主裂纹 path + `mask` 啃出来的崩口 + 亮边 + CSS 掉落碎片。
档位只是给根节点挂 `data-tier="0..3"`，外观全在 CSS 里，加档位不用动 JS。

## 环心血条（v2）

心外面一圈细环 = 血条：**剩下的命就是这一圈还剩多少**，从 12 点方向顺时针走。

- 环的颜色跟着档位走：粉红 → 暗红 → 深红 → 低血时红着闪
- 读数取不到时环淡到 45%，不假装满血
- 环不挡点击（整块一起拖）

实现：SVG `circle` + `stroke-dasharray`，paint() 里按剩余百分比算长度，CSS 负责过渡和低血脉动。

## 挤压 / 抽离（v3）

右键菜单最上面两项。**插件不自己压缩、也不自己写记忆**——它替你按发送，活是 DSH 和露露干的。

| 项 | 干什么 | 怎么干 |
|---|---|---|
| **挤压** | 把上下文里旧的对话压扁，腾出余量 | 往输入框送 `/compact` 并回车，走 DSH 内置压缩；压实了心会回一点血 |
| **抽离** | 把这段会话值得留的东西写到记忆/文件，上下文只留一条指针 | 送一段固定提示词，露露照做；**要点两次**才发（会开始一轮对话） |

安全闸：

- 输入框里已经有草稿 → 不动，弹提示
- 这一轮还在跑（输入框锁着）→ 不动，弹提示
- 塞进去后发送键没亮 / 没塞进去 → 收回，不硬发

这一条很重要：**它不改会话、不伪造消息**，走的都是"用户按下发送"那条路。

### v3.1：菜单里的解释、注意事项、小图标

两项各带一枚内联 SVG 小图标（挤压＝上下箭头向中间压；抽离＝漏斗往下滴），下面一行灰字说明「干什么」，再一行橙字带「注意」小标签写风险：

| 项 | 图标 | 说明 | 注意 |
|---|---|---|---|
| 挤压 | 上下箭头压向中间 | 把对话压成一段摘要，腾出上下文余量。压缩是 DSH 在干，爱心只替你按发送。 | 要跑一会儿，期间输入框被占住；摘要换不回原文。 |
| 抽离 | 漏斗 + 往下滴 | 让露露把决定、踩坑、约定和偏好写进记忆或文件，上下文里只留一条指针。 | 要点两次才发，会真开一轮对话；没落盘等于没留下。 |

- 点第一下「抽离」时整张卡高亮成粉色、右侧徽标变「确认？」，4 秒不点自动复位
- 菜单宽 336px；菜单开着时提示条会自动让到菜单下面，不盖住菜单
- 图标是内联 SVG，不依赖字体/图标库，`fill/stroke` 都写成属性，CSS 丢了也不变形

## 数据来源

读 DSH 自带上下文计量表（输入框下方那个很小的圆圈）的 DOM：

- 百分比：`[class*="JObwrW_trigger"]` 的文字或 `aria-label`（`上下文已用 46%`）
- 兜底选择器：`[aria-label*="上下文"]` → 任何 aria-label 里带 `%` 且像上下文的元素 → `[class*="JObwrW_root"]` 里的按钮
- 分段（系统 / 工具 / 对话）与总量：分段只在自带面板打开时才有，所以**只在我们自己面板打开时**用 `click()` 点开一次、读完立刻关掉（读的时候把面板 `visibility:hidden`，避免闪一下）

读数拿不到时**不画成 0%**：保持上一次的值，菜单和面板里标「读数暂不可用」。

## 注意

1. `JObwrW_*` 是 CSS Modules 哈希类名，**DSH 升级后可能变**；所有读取都有 aria-label 兜底，但升级后最好重新跑一次 `E:\露露训练\tools\verify-ctxheart.mjs`。
2. 与自带的计量表**并排工作**，不隐藏、不替换它。
3. 本插件只读 DOM、不改宿主，出问题删掉 bundle 行即可恢复。
